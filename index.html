Controllo vocale CNC dal browser

Leggi il tutorial completo su Instructables →

Instructables contiene la procedura passo passo, mentre questa pagina contiene il programma CostyCNC e la documentazione tecnica del sistema.

Cos'è questa pagina

Questa pagina permette di controllare una macchina CNC tramite comandi vocali in italiano oppure tramite pulsanti, direttamente dal browser.

I comandi vocali vengono interpretati dalla pagina e trasformati in istruzioni G-code, che vengono inviate tramite HTTP al controller della macchina attraverso la rete WiFi.

Il sistema può essere utilizzato con macchine CNC, laser, fresatrici e macchine a filo caldo (hot wire), purché il controller disponga di WiFi e di un web server in grado di ricevere comandi G-code tramite richieste HTTP.

Compatibilità con controller CNC WiFi

Il sistema non è legato a una particolare macchina. Può funzionare con controller basati su ESP32 o ESP8266 e con altri controller che espongono un'interfaccia web per l'invio di comandi G-code.

Sono supportate sia le configurazioni WiFi AP (Access Point) sia STA (Station), quando il controller permette di ricevere richieste HTTP dalla rete.

Il requisito principale è che il controller accetti una richiesta HTTP di questo tipo: 

http://{IP}/command?commandText=[GCODE]

Compatibilità con CostyCNC

Il sistema è compatibile anche con CostyCNC, macchine CNC a filo caldo progettate per il taglio di polistirolo, EPS, XPS e foam.

Le macchine CostyCNC utilizzano controller MKS-DLC32 basati su ESP32 e dotati di WiFi. Il controllo vocale può quindi essere utilizzato per inviare comandi di movimento e altre istruzioni G-code direttamente dal browser.

Comandi vocali disponibili

Comando vocale Azione
"avanti" Muove l'asse X di +D mm (default 10 mm).
"avanti 100" Muove l'asse X di +100 mm.
"dietro" Muove l'asse X di −D mm (default 10 mm).
"dietro 50" Muove l'asse X di −50 mm.
"su" Muove l'asse Y di −D mm (default 10 mm).
"su 25" Muove l'asse Y di −25 mm.
"giù" Muove l'asse Y di +D mm (default 10 mm).
"giù 30" Muove l'asse Y di +30 mm.
"gira" Muove l'asse Z di 8 mm (default).
"gira 12" Muove l'asse Z di 12 mm.
"taglia" Esegue il file G-code indicato nella configurazione della pagina e salvato sulla scheda SD della MKS-DLC32. Il nome predefinito è costycnc.nc, ma può essere sostituito con un altro nome, ad esempio maria.nc.

Parametri configurabili

  • IP ESP: indirizzo IP del controller sulla rete locale, ad esempio 192.168.1.36.
  • PWM / Caldo (S): valore di potenza utilizzato dal laser o dal filo caldo.
  • Velocità (F): velocità di movimento in mm/min.
  • Movimento (D): distanza utilizzata quando il comando vocale non contiene un valore numerico.
  • File G-code: nome del file .nc presente sulla scheda SD della MKS-DLC32 che deve essere eseguito con il comando vocale "taglia".

Le impostazioni e le caselle G-code vengono salvate nel localStorage del browser.

Esecuzione di un file G-code dalla scheda SD

Il comando vocale "taglia" avvia il file G-code indicato nella configurazione della pagina e presente sulla scheda SD della MKS-DLC32.

Il nome predefinito del file è costycnc.nc. Questo nome non è obbligatorio e può essere modificato.

Per esempio, puoi creare o salvare sulla scheda SD il file maria.nc. Nella pagina modifichi il nome del file da costycnc.nc a maria.nc.

A questo punto, pronunciando "taglia", la pagina invia il comando per eseguire maria.nc dalla scheda SD. La macchina eseguirà quindi il G-code contenuto nel file maria.nc.

In questo modo il comando vocale rimane sempre lo stesso: "taglia". È il nome del file configurato nella pagina a stabilire quale programma G-code deve essere eseguito.

Come vengono inviati i comandi

I comandi di movimento vengono trasformati dalla pagina in richieste HTTP contenenti G-code. Ad esempio: 

http://{IP}/command?commandText=M03 S{S} G91 G21 F{F} G01 X{n}

Dopo ogni comando di movimento viene inviato automaticamente S0 per spegnere il filo caldo.

Riconoscimento vocale

Il riconoscimento vocale utilizza la Web Speech API. Il funzionamento dipende dal supporto del browser e dalla disponibilità del riconoscimento vocale sul dispositivo.

È possibile utilizzare browser come Google Chrome e Microsoft Edge, oltre ad alcuni browser compatibili su dispositivi Android.

Domande frequenti

Come si controlla una CNC con la voce?

Il browser riconosce il comando vocale in italiano, lo interpreta e lo converte in un comando G-code. Il comando viene quindi inviato tramite HTTP al controller CNC attraverso la rete WiFi.

Quali CNC sono compatibili?

Sono compatibili i controller che dispongono di WiFi e di un web server capace di ricevere richieste HTTP contenenti comandi G-code.

La MKS-DLC32 è compatibile?

Sì. La MKS-DLC32 è basata su ESP32 e dispone di connettività WiFi. Quando è configurata per ricevere comandi tramite la propria interfaccia web, può essere utilizzata con questa pagina.

È compatibile con CostyCNC?

Sì. Le macchine CostyCNC compatibili utilizzano controller MKS-DLC32 con WiFi e possono ricevere comandi G-code tramite la rete.

Quale file viene eseguito quando dico "taglia"?

Viene eseguito il file .nc indicato nella configurazione della pagina e presente sulla scheda SD della MKS-DLC32.

Il nome predefinito è costycnc.nc, ma puoi cambiarlo. Ad esempio, se sulla scheda SD hai maria.nc e nella pagina hai impostato maria.nc come file da eseguire, pronunciando "taglia" verrà eseguito maria.nc.

È necessario installare un programma?

Il controllo viene eseguito direttamente dal browser. Non è necessario installare un software CNC dedicato per utilizzare questa interfaccia.
